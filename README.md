# Eco | Clima

Visualizador de datos climáticos (archivos EPW) desarrollado por **ECO Consultor**
como apoyo a nuestros estudios de eficiencia energética y confort térmico en
edificaciones.

Construido con [Streamlit](https://streamlit.io) y
[ladybug-charts](https://github.com/ladybug-tools/ladybug-charts).

## Ejecutar la app localmente

```
pip install -r requirements.txt
streamlit run app.py
```
